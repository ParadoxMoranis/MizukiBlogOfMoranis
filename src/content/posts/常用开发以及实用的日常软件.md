# 常用开发以及实用的日常软件

## 开发相关软件

### 1.VSCode（注意与VS2022等区分）：万能轻量编辑器

[Visual Studio Code 官网](https://code.visualstudio.com/)

作为全能的IDE，拥有丰富的插件市场，无论是硬件还是软件领域都有举足轻重的地位。

支持系统的MCP协议，内核开源。

![](C:\Users\Moranis\AppData\Roaming\marktext\images\2025-10-14-13-56-38-image.png)

### 2.JetBrains全家桶：专业的IDE

[JetBrains官网](https://www.jetbrains.com/)

JetBrains有对几乎所有主流语言支持的IDE，python，C/C++，Java, Rust，还有数据库的管理软件。安卓官方的开发工具AndroidStudio也是基于JetBrains的IDE开发。

![](C:\Users\Moranis\AppData\Roaming\marktext\images\2025-10-14-13-59-42-image.png)

插件市场丰富，界面非常现代化，边界的功能非常多。满分推荐。

> 由于JetBrains的IDE均为Java开发，相对VSCode更加需要硬件支持（主要是内存）

### HexHub：不仅仅是ssh工具

[HexHub | 先进的数据库、SSH、SFTP桌面GUI工具](https://www.hexhub.cn/)

HexHub的免费版可以以项目（官方称之为资产）的形式管理你的ssh，docker，数据库等资源，为SSH等提供了非常好的便利。

![](C:\Users\Moranis\AppData\Roaming\marktext\images\2025-10-14-14-04-30-image.png)

### WSL：便捷好用的Linux子系统

[Windows Subsystem for Linux 文档 | Microsoft Learn](https://learn.microsoft.com/zh-cn/windows/wsl/)

[WSL的特性以及一些使用技巧 - Moranis个人博客](https://moranisz.netlify.app/posts/wsl%E7%9A%84%E4%BD%BF%E7%94%A8/)

WSL作为Win的子系统，可以很方便的在Linux使用主机的硬件资源。对于只有一台机器又不想折腾双系统和虚拟机的同学，这是一个玩Linux的好的方案。我个人也在使用。推荐Ubuntu的操作系统。

![](C:\Users\Moranis\AppData\Roaming\marktext\images\2025-10-14-14-09-44-image.png)

## 日常软件

### FlowLauncher：快捷的应用启动器

[GitHub - Flow-Launcher/Flow.Launcher](https://github.com/Flow-Launcher/Flow.Launcher)

FlowLauncher在Windows提供了类似Rofi的启动器体验，通过快捷键操作，支持文件查找，应用启动，唤起浏览器搜索等功能。Flow launcher的社区和插件非常丰富成熟，可以提供便捷的体验。

![](C:\Users\Moranis\AppData\Roaming\marktext\images\2025-10-14-14-13-37-image.png)

### MarkText&Typora：知名的轻量简洁的Markdown编辑器

[GitHub - marktext/marktext: 📝A simple and elegant markdown editor, available for Linux, macOS and Windows.](https://github.com/marktext/marktext)

![](C:\Users\Moranis\AppData\Roaming\marktext\images\2025-10-14-14-16-59-image.png)

此时此刻我在写文档就是使用了MarkText。当然，如果你喜欢更丰富的功能，可以使用VSCode或者Obsidian。

[教程：8分钟学会Markdown](https://www.bilibili.com/video/BV1JA411h7Gw/?share_source=copy_web&vd_source=531032478db11b1deb9b055e9157db27)

> Typora支持各种主题，但是Typora需要破解，这里不做解释同学们自行搜索。

### BandZip：免费但是有广解压工具

  [Bandizip 官方网站 - 免费压缩软件下载 (Windows)](https://www.bandisoft.com/bandizip/)

支持各种压缩格式的解压，界面简洁功能强大。

![](C:\Users\Moranis\AppData\Roaming\marktext\images\2025-10-14-14-21-58-image.png)

### PotPlayer：强大的视频播放器

[Global Potplayer](https://potplayer.daum.net/)

![](C:\Users\Moranis\AppData\Roaming\marktext\images\2025-10-14-14-23-14-image.png)

伟大无需多言，支持推流，能播放各种格式的音频视频文件。

### RustDesk：开源，免费可自建的远程桌面软件

[GitHub - rustdesk/rustdesk: An open-source remote desktop application designed for self-hosting, as an alternative to TeamViewer.](https://github.com/rustdesk/rustdesk)

RustDesk功能强大，开源免费。有公共服务也可以自己在服务器部署中转，安全性便捷性全部拉满。

![](C:\Users\Moranis\AppData\Roaming\marktext\images\2025-10-14-14-27-12-image.png)
